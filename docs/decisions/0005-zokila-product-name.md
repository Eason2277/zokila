# 决策 0005：产品命名为走起啦 · Zokila

- 日期：2026-11-15
- 状态：用户已确认产品名称；对外使用前仍需核查名称可用性
- 关联：0004 个人旅行与出行产品方向

## 背景

用户希望中英文名称在读音上有关联，语气年轻、俏皮，像朋友招呼出发。曾喜欢“走哇 · Zowa”，但公开搜索发现中英文已有同名使用，因此继续寻找名称。

## 决定

本产品采用 **走起啦 · Zokila** 作为中英文名称。中文表达出发的邀请；英文将“走起啦”的语感浓缩为便于记忆的拼写。项目文档统一使用此名称，代码目录和旧原型界面暂不因此改名。

## 边界与后续核查

- 命名选择不等于商标可注册、应用商店名称或域名可用。
- 对外发布前，在目标市场核查商标、近似名称、应用商店及域名，并记录结果。
- 首版用户、旅行场景和技术形态仍按产品文档中的假设推进；本决策只确认名称。
