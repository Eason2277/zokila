# 决策 0004：转向个人旅行与出行助手

- 日期：2026-11-15
- 状态：现行产品方向；首个用户细分与工作流待验证
- 取代：0001 的制造业目标市场研究产品切片

## 背景

用户希望新项目面向普通人的个人生活消费，最终明确选择旅行与出行方向。现有制造业后台 Agent 项目已覆盖另一类业务。当前仓库里的桌面界面和文档仍以制造业市场研究为主题，尚未接入 Pi SDK 或真实数据。

## 决定

将本项目定位为个人旅行与出行助手，先假设帮助个人规划并调整一次短途自由行。将目的地、日期、预算、兴趣、同行人和现实约束整理成可编辑的行程，并为时效性信息显示来源与核查状态。保留用户对预订和购买的最终决定权。

“企业级”用于描述工程质量、权限、数据保护和可靠性目标，不表示首版面向企业采购或企业差旅。

## 理由与取舍

- 与现有制造业后台项目形成不同的用户和工作流，展示面向个人用户的全栈及 AI 应用能力。
- 旅行规划涉及多约束、多来源、工具调用、持久状态和用户修订，适合评估 Pi 作为 Agent 底座的适用性。
- 外卖、穿搭、美妆和礼物可作为未来消费方向，但先聚焦旅行，避免各场景的数据和验证问题同时扩散。

## 风险与待验证项

- 用户细分和最有价值的旅行任务尚未通过访谈或真实使用验证。
- 地点、营业时间、交通、价格和库存高度依赖外部数据及其时效；数据源和授权未确定。
- 当前市场研究 UI 与目录名是历史产物，不能据此宣称旅行功能已实现；改造时另行评估桌面形态是否适合个人用户。
- 个人地点、日期和偏好数据的发送、保存、删除与保留期限尚需设计。

## 重新评估条件

用真实或脱敏旅行计划验证工作流。如果用户主要需要其他任务，或可用数据源不足以支撑可信行程，应调整首版切片与产品形态，并记录新决定。
